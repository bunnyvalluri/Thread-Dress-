Design system

A calm, editorial visual language built around natural materials, clear hierarchy and easy shopping.

01 · Colour palette

Warm ivory · Forest green · Sage · Deep ink · Clay accent

02 · Typography
Everyday, considered.
Clear sans-serif for navigation, labels and product information.

Editorial serif headings create a warm, premium feel.

03 · Components

Buttons use clear action labels, visible focus and consistent spacing.

04 · Layout

12-column grid

Wide desktop gutters, consistent spacing and flexible product grids.

05 · Imagery

Natural, honest, tactile

Use bright natural light, neutral backgrounds and close-up fabric details.

06 · Accessibility

Readable by design

Semantic headings, descriptive image text, keyboard access and strong contrast.

Shopper user journey

A simple path from first visit to order confirmation. Each step should make the next action obvious.

STEP 01DiscoverArrive on homepage, understand the brand and see collections.
STEP 02ExploreBrowse categories, search products and apply filters.
STEP 03EvaluateReview photos, description, price, sizes and availability.
STEP 04PurchaseAdd to bag, review order and continue to secure checkout.

Key UX decisions

Easy discovery
Keep category navigation visible and product search easy to find.
Useful product detail
Show price, sizes, materials and clear product photography.
Clear feedback
Confirm add-to-bag actions and show cart quantity.
Mobile first
Use touch-friendly controls and a single-column layout on small screens.
